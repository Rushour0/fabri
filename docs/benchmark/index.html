The discipline

01 · Completion gate

An incomplete run cannot earn a rubric score. Operational failure and output quality are measured separately, never conflated.

02 · No-op rejection

A config change that provably does nothing spends nothing. Candidates are bounded and rejected at preflight.

03 · Recursive cost

Every sub-agent's cost is counted into the total — static specialists and spawned children alike, all the way down.

What this does & doesn't prove

Proven

  • The current Support HQ setup reliably completes this incident-response workload. 3/3 replicas, end-to-end, isolated state per run.
  • It does so at a known, recursively-accounted cost. ~$0.02 per run, median across replicas.

Not proven — yet

  • That memory improves company performance. The memory-vs-control study is the next experiment.
  • That it holds across other companies or task types. One company, one workload, three replicas.
  • That the setup search finds an optimal configuration. Only one bounded token-floor hypothesis has been tested.
